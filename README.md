# PrismPane Editor

A simple desktop editor for Markdown and JSON.

## What It Does

* Edit Markdown and JSON files.
* Open folders and browse files in a sidebar.
* Preview Markdown while you type.
* Save tabs and recent folders between sessions.
* Export Markdown content to HTML or PDF.

## Main Features

* Multi-tab editing
* Folder tree navigation
* Markdown preview
* JSON formatting
* Outline view
* Themes
* Templates
* Command palette and shortcuts
* Zen and typewriter mode

## Run It

```bash
npm install
npm run tauri dev
```

## Build It

```bash
npm npm run tauri build
```
